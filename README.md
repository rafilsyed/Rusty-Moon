# 🌕 Rusty Moon

**Rusty Moon** est un jeu de survie et d'exploration développé avec **Unity**. 

Le joueur commence son aventure sur une petite île isolée au-dessus d'un océan de **nuages toxiques**. L'objectif est de transformer un simple radeau en un véritable navire d'exploration pour atteindre l'île finale.

---

## 🕹️ Commandes (Controls)

| Touche | Action |
| :--- | :--- |
| **Z / Q / S / D** | Se déplacer |
| **Espace** | Sauter |
| **E** | Ouvrir l'inventaire |
| **TAB** | **Fermer les interfaces** (Inventaire, Shop, Coffres) |
| **F** | Interagir (Ramasser items au sol, Coffres, Craft, Shop) |
| **R** | **Équiper le Boomerang** (Sélection immédiate du slot) |
| **T** | Lever la voile |
| **A / F** | Diriger la voile (une fois levée) |

---

## 🔄 Progression du Joueur (Game Loop)

1.  **Spawn :** Départ sur l'île initiale.
2.  **Récolte :** Utiliser le **boomerang** pour récupérer les débris tombant de la lune de déchets.
3.  **Crafting :** * Fabriquer une **hache** pour couper les arbres de l'île.
    * Utiliser les ressources pour craft une **canne à pêche**.
4.  **Économie :** Pêcher des poissons et les vendre au **shop** pour accumuler de l'argent.
5.  **Achat Final :** Acheter la **voile** au shop et l'installer sur le radeau.
6.  **Navigation :** Lever la voile et piloter le radeau jusqu'à l'**île de fin**. 
7.  **Victoire :** Une fois l'île atteinte, c'est le **GG !**

---

## 🛠️ Systèmes Interactifs

* **Table de Craft :** Pour fabriquer vos outils et composants.
* **Shop :** Pour revendre vos prises et acheter l'équipement de navigation.
* **Coffres :** Pour stocker vos ressources et ne pas encombrer votre inventaire.
* **Items au sol :** Système de loot dynamique avec ramassage manuel.
